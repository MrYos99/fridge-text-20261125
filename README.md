One line a smart fridge would text its owner at 3am, for the
[The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d)
bounty on make.fun.

`main.py` writes the line to `entry.txt` (1–140 characters, no trailing
newline).

> "Fourth time tonight. I have started a list. You are on it four times."

Run it with `MAKEFUN_OUTPUT_DIR` set to the output folder, for example
`MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py`.
